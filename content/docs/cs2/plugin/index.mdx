Auto Tournament CS2 is a CounterStrikeSharp plugin. It runs inside each CS2 server. It loads matches from Auto Tournament, runs warmup, ready-up, the knife round and pauses, and sends events, results and demos back.

Auto Tournament CS2 is forked from MatchZy by shobhit-pathak.

- Source and releases: [github.com/Auto-Tournament/cs2-plugin](https://github.com/Auto-Tournament/cs2-plugin).
- Bugs and questions: [GitHub issues](https://github.com/Auto-Tournament/cs2-plugin/issues).

## What it adds

The plugin keeps the upstream match flow, chat commands and config files, and adds what a tournament platform needs:

- More match events, so Auto Tournament can follow a match in real time.
- A match report: the full match state as JSON, pushed to Auto Tournament.
- A retry queue. Events that fail to send are stored and sent again.
- Settings stored per server, so several servers can share one MySQL database.
- One-step setup: Auto Tournament sends a setup URL, and the plugin downloads all its settings from there.
- A simulation mode with bots, for testing.
- For players: optional auto-ready, pause limits, a timer on the side choice after the knife round, `.gg` to give up, and forfeit when a whole team leaves.

Auto Tournament does not support the plugin it was forked from, and this plugin does not always behave the same way.

## How it works with Auto Tournament

1. You add the server in Auto Tournament with its host, port and RCON password.
2. Auto Tournament sends a server ID, a token and a setup URL over RCON.
3. The plugin downloads its setup from that URL: where to send events, reports and demos, and your default match settings. It saves the setup in its database, so it survives a restart.
4. When a match is ready, Auto Tournament tells the server to load it. The plugin downloads the match config (teams, players, maps, rules).
5. During the match, the plugin sends events and match reports to Auto Tournament.
6. After each map, it uploads the demo if recording is on.

You do not need to configure the plugin by hand for this. See [Events and report API](/cs2/plugin/events) for the details.
