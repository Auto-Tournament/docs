CS2 Server Manager (`csm`) is a command-line tool with a menu in the terminal. On one Linux machine it:

- installs CS2 with SteamCMD,
- sets up Metamod:Source, CounterStrikeSharp and [Auto Tournament CS2](/cs2/plugin) (formerly MatchZy Enhanced) on every server,
- runs each server in its own tmux session,
- keeps the game and the plugins updated.

It is made for Auto Tournament, but works for any setup that needs several CS2 match servers. Auto Tournament then controls the servers over RCON.

## How it is set up

The servers run as the Linux account that runs `csm`, and everything lives in that account's home folder:

| Path | What it is |
| --- | --- |
| `~/master-install/` | One full CS2 install. SteamCMD only updates this one. |
| `~/server-1/`, `server-2/`, ... | One folder per server. The large game files are shared with `master-install`, so each extra server uses about 2 GB. |
| `~/overrides/game/` | Your own config files. They survive updates. |
| `~/logs/server-1.log` | The console log of each server. |

`csm` keeps its own state and logs there too (`~/logs/csm.log`).

Server `N` runs in the tmux session `cs2-N`.
