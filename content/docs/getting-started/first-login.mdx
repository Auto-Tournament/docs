A new install has no admin. The first admin is a local account (username and password) that you create with a one-time setup code from the container log. After that you can sign in with any provider you turn on.

<Steps>

<Step>

### Get the setup code

On its first start, Auto Tournament writes a setup code to its log:

```bash
docker compose logs auto-tournament | grep SETUP
```

The code works once and expires after 24 hours. Restart the container for a new one.

</Step>

<Step>

### Create the admin

Open Auto Tournament in the browser. The login page links to **Set up the first admin** (`/setup`). Enter the code, then pick a username and password. You are signed in as admin.

From then on, sign in with that account at `/login/admin`. You can turn on two-factor codes for it.

</Step>

<Step>

### Accept the license terms

The first time you open the admin pages, you choose how you use Auto Tournament (for example a free community event, or commercial use with a license). See [Licensing](/reference/licensing).

</Step>

<Step>

### Turn on sign-in for players

In **Settings → Sign-in**, turn on the providers your players use: Steam, Discord, Google, GitHub, Twitch, Epic Games or your own OpenID Connect server. See [Sign-in providers](/guides/sign-in).

To sign in with one of them yourself as admin, sign in once, then make that account admin (see below).

</Step>

<Step>

### Set up your game

Settings has a tab for each installed game. For CS2, open **Settings → Counter-Strike 2** and check that **Webhook URL** is an address your game servers can reach (not `localhost` when they run on another machine). Then click **Sync CS2 Maps** to fetch the map list.

Continue with [Connect a CS2 server](/getting-started/connect-server), or [Manual reporting](/guides/manual-reporting) for games without servers.

</Step>

</Steps>

## Making more admins

Admin rights belong to the account, whatever sign-in method it uses. There are three ways to make someone admin:

- On the **Players** page, edit the player and turn on **Is admin**.
- In **Settings → Sign-in → Admin access**, add their email address to **Admin emails**. They become admin when they sign in with a provider that has verified that address (for example Google).
- In the same place, add their Steam64 ID to **Admin Steam IDs**. Those accounts are made admin at every start and when you save.

The lists only add admins. Removing someone from a list does not take admin away; turn off **Is admin** on the Players page for that.

## Locked out

If nobody can sign in as admin any more, create a new setup code on the host:

```bash
docker exec auto-tournament reset-admin
```

Then open `/setup` and enter it. This also turns the local admin login back on if it was switched off.
