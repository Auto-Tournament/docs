When players pick the games they play ("What do you play?"), they search a game catalogue. It works out of the box: there are no keys to set up.

## Where the games come from

- **Built-in games**: every game an installed module or game pack runs, and a short list of popular esports titles. They are always there, even offline.
- **Search**: other games come from [Wikidata](https://www.wikidata.org), a free, open database. A game someone found is saved, so the next search for it is instant.

Built-in games get a picture, their release year and their genres from Wikidata as well. That happens in the background after the platform starts, and again once a week. A game pack's own app icon is used where it has one.

## Offline and firewalled installs

Search needs the platform to reach `www.wikidata.org`. Without it, players can still pick the built-in games, and those show their name without a picture. Nothing else depends on it.

To turn the background lookups off, for example in a test setup, set:

```bash title=".env"
GAMES_ENRICH=off
```

## Earlier versions

Before 3.0 beta, game search used IGDB with a Twitch developer key. That was removed: the `IGDB_CLIENT_ID` and `IGDB_CLIENT_SECRET` settings do nothing any more and can be deleted from `.env`.
