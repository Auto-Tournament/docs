Open **Settings** in the admin menu. Everything on this page is stored in the database and applies without a restart. The few settings that live in `.env` are described in [Configuration](/reference/configuration).

## The tabs

| Tab | What is on it |
| --- | --- |
| Integrations | The site name shown in the browser tab and on public pages. |
| Sign-in | The sign-in providers (Steam, Discord, Google, GitHub, Twitch, Epic Games, OpenID Connect), each with a test button, the callback URL and a setup guide. **Admin access**: admin emails, admin Steam IDs and whether the local admin login is on. See [Sign-in providers](/guides/sign-in). |
| Players & Access | **Player registration**: whether signing in creates an account for someone new, whatever sign-in method they use. Turn it off to only allow players an admin created or imported. |
| Ratings | Whether completed matches change player ratings. |
| License | Paste your [license key](/guides/license), see its status, and turn on the public "Licensed" line. |
| Webhooks | Webhooks for your event website: where to send match events, the signing secret and test events. See [Webhooks](/reference/webhooks). |
| Experimental | Features that are still being built, off by default. |
| One tab per game | Settings of each installed game module. For **Counter-Strike 2**, see below. |
| Developer | [Simulation mode](/guides/simulation-mode) and developer helpers. Only in builds with developer tools, not in the published Docker image. |

## Counter-Strike 2

- **Webhook URL**: the address MatchZy Enhanced servers send events and demos to. Ready Up servers use the fleet link instead and do not need it.
- **Sync CS2 Maps**: fetch the CS2 map list and the Active Duty pool.
- **Server defaults** for MatchZy Enhanced servers: chat prefix and knife round, demos, the end-of-series wait, ready and match start, server access, admin tools, auto-ready, pauses, side selection, `.gg`, forfeit, and the **Server hostname format**. Leave a field empty to use the plugin's own default. They are sent to a server before each match loads, so a change applies to the next match, not to one already running.

Ready Up servers get their settings, in-game admins, whitelist, practice mode and plugins from **Fleet settings** on the **Servers** page, pushed over the fleet link. See [Fleet mode](/cs2/ready-up/fleet).

## Change the server name

By default, a server takes the name `{TEAM1} vs {TEAM2}` when a match loads.

<Steps>

<Step>

### Open the CS2 settings

Open **Settings → Counter-Strike 2**.

</Step>

<Step>

### Set the format

In **Server hostname format**, enter the name you want. You can use these tokens: `{MATCH_ID}`, `{MAP}`, `{MAPNUMBER}`, `{TEAM1}`, `{TEAM2}`, `{TEAM1_SCORE}`, `{TEAM2_SCORE}`. For example:

```text
Summer Cup | {TEAM1} vs {TEAM2}
```

Leave the field empty to keep the hostname from each server's own `server.cfg`. The name is set on every match load, so an empty field is the only way to keep yours.

</Step>

<Step>

### Save

Save the settings. The next match that loads uses the new name.

</Step>

</Steps>

## Stop matches from changing ratings

On the **Ratings** tab, turn off **Rating Updates**. Use this when another system decides the ratings for your event.
