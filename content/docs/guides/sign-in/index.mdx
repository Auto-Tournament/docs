Auto Tournament can show a sign-in button for each of these providers:

| Provider | Protocol | Guide |
| --- | --- | --- |
| Steam | OpenID | [Steam](/guides/sign-in/steam) |
| Discord | OAuth2 | [Discord](/guides/sign-in/discord) |
| Keycloak | OpenID Connect | [Keycloak](/guides/sign-in/keycloak) |
| GitHub | OAuth2 | [GitHub](/guides/sign-in/github) |
| Google | OAuth2 with OpenID Connect scopes | [Google](/guides/sign-in/google) |
| Twitch | OAuth2 | [Twitch](/guides/sign-in/twitch) |
| Epic Games | OpenID Connect | [Epic Games](/guides/sign-in/epic) |

Turn them on in **Settings → Sign-in**: paste the client ID and secret, and copy the callback URL shown there into the provider's console. The login page shows one button per provider that is turned on and fully set up. You can turn on more than one.

## Steam is optional

Any sign-in method can be someone's account. The first time someone signs in with Discord, Google, GitHub, Twitch, Epic Games or Keycloak, they get an account of their own when registration is open (**Settings → Players & Access**). With registration closed, they are asked to sign in with Steam to finish.

People can link more sign-in methods, Steam included, on **/me/connections**. Games that need Steam, such as CS2, only put players with a linked Steam account on their servers.

## Admin sign-in

Local admin accounts (username and password) do not have a button on the login page. Admins sign in at:

```text
https://tournament.example.com/login/admin
```

Enter the username, the password and, when two-factor sign-in is on, the code from your authenticator app. Bookmark the page.

The first local admin is created on a new install: the container log prints a one-time setup code, and you enter it at `/setup`. See [First login](/getting-started/first-login).

Locked out? Run this on the host. It prints a new one-time code for `/setup`:

```bash
docker exec auto-tournament reset-admin
```

## Admin access

You get admin rights in one of these ways:

- You are a local admin (see above).
- An existing admin edits your player on the **Players** page and turns on **Is admin**.
- Your Steam64 ID is in `ADMIN_STEAM_IDS` in `.env`. See [If you are not admin](/getting-started/first-login#if-you-are-not-admin).

Admin rights belong to the account, whatever button you used to sign in.

## Callback address

Each provider sends you back to Auto Tournament after sign-in. The address is `FRONTEND_BASE_URL` followed by the provider's callback path, for example:

```text
https://tournament.example.com/api/auth/github/callback
```

If the API has another public address than the web app, set `BACKEND_BASE_URL`. The callback then uses that address instead of `FRONTEND_BASE_URL`.

The address you register at the provider must match exactly: same scheme (`http` or `https`), same host, same port, no slash at the end.

## Check which providers are on

This shows the providers the login page will show:

```bash
curl -fsS http://localhost:3069/api/auth/providers
```

A provider with `"enabled": true` has a button. A provider that is missing is not turned on, or is missing its client ID or secret.

All sign-in variables are listed in [Configuration](/reference/configuration#sign-in-providers).
