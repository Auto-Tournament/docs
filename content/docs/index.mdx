Auto Tournament runs tournaments on game servers that you own. You create the teams and the bracket. Auto Tournament picks a free server, loads each match, runs the map veto in the browser, and moves the bracket forward when a match ends.

Counter-Strike 2 (CS2) runs on servers with [Ready Up](/cs2/ready-up), our own plugin. Any other game can run too, with the captains reporting the score. The project was called **MatchZy Auto Tournament** (MAT) up to version 2.4. The old Docker image name, `sivertio/matchzy-auto-tournament`, still gets every release. Coming from 2.x? See [Upgrading to 3.0](/guides/upgrading-to-3).

## Who it is for

- LAN organisers who run CS2 events on their own servers.
- Small leagues and communities that want brackets, veto and results in one place.
- Groups of friends who want a quick 5v5 or 2v2 with balanced teams.

You host everything yourself. Auto Tournament is one Docker image plus a PostgreSQL database.

## What it does

- Single elimination, double elimination, round robin, Swiss and shuffle tournaments.
- Team sign-up and check-in.
- Map veto for best of 1, 3 and 5, done on a web page for each team.
- Creates, starts and updates servers on your machines with [CS2 Server Manager](/cs2/server-manager), loads each match on a free one, and frees it when the match ends.
- A match room for each match, with the live score, server status and connect info.
- [Highlights](/guides/highlights): clips and reels of each player's best plays, recorded from the demos.
- Demo recording and download, with stats and a 2D replay.
- Skins that players pick on the site and see on your servers.
- Player ratings and leaderboards.
- A [Discord bot](/modules/discord) with channels for each tournament and team.
- 30 languages.
- An HTTP API with API tokens, for bots and scripts, and an [AI connection](/guides/ai) for Claude and other MCP clients.
- A simulation mode for testing a tournament with bots.
- [Matchmaking](/guides/matchmaking), still experimental.
