MatchZy Enhanced (ME) is the CS2 server plugin of Auto Tournament 2.x, built on MatchZy with Metamod:Source and CounterStrikeSharp. Auto Tournament 2.x talks to it over RCON and webhooks.

**MatchZy Enhanced is not supported in Auto Tournament 3.x.** From 3.x, servers run [Ready Up](/cs2/ready-up), the native CS2 plugin: no Metamod or CounterStrikeSharp, one outbound link to the platform (no RCON, no inbound port), demos streamed while they record, failover and auto-scaling. To move a server, see [Upgrading to 3.0](/guides/upgrading-to-3).

## Which version for which platform

| Auto Tournament | MatchZy Enhanced | Settings start with |
| --- | --- | --- |
| 2.x | 1.4.x (1.4.35 is the last) | `matchzy_` |
| 3.x | Not supported: use [Ready Up](/cs2/ready-up) | |
