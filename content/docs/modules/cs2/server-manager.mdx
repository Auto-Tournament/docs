CS2 Server Manager (`csm`) is a command-line tool with a menu in the terminal. On one Linux machine it installs CS2, sets up Metamod:Source, CounterStrikeSharp and the Auto Tournament CS2 plugin (formerly MatchZy Enhanced) on every server, runs each server in tmux, and keeps the game and the plugins updated.

It is the easiest way to get servers for Auto Tournament. The full docs have their own section:
