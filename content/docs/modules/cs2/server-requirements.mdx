## The machine

For CS2 Server Manager:

- Linux on `x86_64` or `arm64`. Debian and Ubuntu are the tested systems.
- An ordinary user account to run csm, with `sudo` for the one-time `sudo csm setup-host`. csm refuses to run as root.
- At least 8 GB RAM, and 1 to 2 GB more for each server.
- About 70 GB of disk for CS2. In instance mode every server shares that one install, so ten servers need about as much disk as one; without it, each server is a full copy. See [How much disk? in the csm README](https://github.com/Auto-Tournament/cs2-server-manager/blob/master/README.md#how-much-disk).
- Docker only for the older MatchZy Enhanced stack's shared MySQL database.

## Software on each server

With **Ready Up**:

- CS2 dedicated server (Steam app 730), kept up to date.
- [Ready Up](/cs2/ready-up). No Metamod:Source or CounterStrikeSharp.
- GOTV on (`tv_enable 1`) if you want demos.

With **MatchZy Enhanced**:

- CS2 dedicated server (Steam app 730), kept up to date.
- Metamod:Source. Use `2.0.0.1411` for now, see the note in [Install MatchZy Enhanced](/cs2/matchzy-enhanced/install#install-metamodsource-and-counterstrikesharp).
- CounterStrikeSharp.
- [MatchZy Enhanced](/cs2/matchzy-enhanced), the same version on all servers.
- An RCON password.
- GOTV on (`tv_enable 1`) if you want demos.

CS2 Server Manager installs either stack.

### SteamCMD on Debian and Ubuntu

If `apt` says `Unable to locate package steamcmd`, the package source is not on. `sudo csm install-deps` tries to fix it (one of the few csm commands that needs root). To do it by hand on Ubuntu:

```bash
sudo add-apt-repository multiverse
sudo apt-get update
sudo apt-get install steamcmd
```

On Debian, add `contrib` and `non-free` to your apt sources, then run `sudo apt-get update` and `sudo apt-get install steamcmd`.

## Game Server Login Token

A CS2 server that players join over the internet needs a Game Server Login Token (GSLT). Create one per server at [steamcommunity.com/dev/managegameservers](https://steamcommunity.com/dev/managegameservers) with app ID 730. The CS2 Server Manager installer asks for it. For a LAN event you do not need one.

## Network

Three connections must work:

| From | To | Port | Used for |
| --- | --- | --- | --- |
| Players | CS2 server | Game port, UDP (default 27015) | Playing |
| Auto Tournament | CS2 server | Game port, TCP (default 27015) | RCON |
| CS2 server | Auto Tournament | The webhook URL, usually TCP 3069 or 443 | Events, results, demos |

GOTV viewers also need the GOTV port (default 27020).

Check the last connection from the CS2 machine:

```bash
curl http://192.168.1.50:3069/api/events/test
```

Replace the address with your webhook URL. The answer must contain `"success":true`.

## Auto Tournament and the servers on one machine

This works. Use the machine's LAN IP, not `localhost` or `127.0.0.1`, in these places:

- The **Host** of each server on the **Servers** page, if Auto Tournament runs in Docker. Inside the container, `localhost` is the container itself.
- `FRONTEND_BASE_URL` and the **Webhook URL**, if players or other machines also use them.
