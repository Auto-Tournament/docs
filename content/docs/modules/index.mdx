A **game module** knows one game. It knows how a match reaches the players, how a result reaches Auto Tournament, and what the app should show while that happens.

The core of Auto Tournament does everything else: teams, players, brackets and pairings, the web app, the API, sign-in, ratings and live updates. None of that knows what game you play.

## The modules

| Module | What it does | Games |
| --- | --- | --- |
| [CS2](/modules/cs2) | Talks to the game servers. Loads the match, reads every round, records the result and the demo. | Counter-Strike 2 |
| [Manual reporting](/guides/manual-reporting) | No server to talk to. A captain reports the score, the opponent agrees, an admin settles a dispute. | Every game you add as a pack, and any game you find through search |

<Callout type="warn" title="Manual reporting arrives in 3.0">
  The current release is 2.4.x and runs Counter-Strike 2 only. Manual reporting is in 3.0, which is in beta.
</Callout>

## Modules and game packs

There are two different things here, and it helps to keep them apart:

- A **module** is code. The two above are built into the app. There is nothing to download or enable.
- A **game pack** is a file. It describes one game — its name, its tile, which stats a captain fills in — and runs on the manual reporting module. It contains no code, which is why you can add one from anywhere.

A fresh install comes with a set of game packs already added: Rocket League, Valorant, League of Legends, Dota 2, Deadlock, Overwatch 2, Rainbow Six Siege, Battlefield 6, Call of Duty, Team Fortress 2, Trackmania, chess, Minecraft, EA Sports FC, Super Smash Bros. Ultimate, Street Fighter 6, Tekken 8, osu! and Age of Empires II. They are ordinary packs: you can remove any of them, and a game you removed stays removed.

### Add a game

Open **Modules** in the menu.

- **Browse** lists the games in the community list, [Auto-Tournament/packs](https://github.com/Auto-Tournament/packs). Pick one and click **Add**. Nothing is fetched until you open Browse.
- **Import a pack** takes a pack file you already have. Pick the `.json` file and its `.svg` tile together.

The game then shows up in the setup wizard like any other.

Want a game that is not in the list? A pack is a short JSON file and a square SVG. The [packs repository](https://github.com/Auto-Tournament/packs) explains the format; open a pull request there and every instance can add it.

## Which module runs a tournament

What decides which module runs is **the game you pick when you create the tournament**. Pick Counter-Strike 2 and the CS2 module runs it: you get the Servers page, map pools, the veto and live scores. Pick Rocket League and manual reporting runs it: no servers, no maps, and a report form on each team's match page instead.

From 3.0 the app follows that choice everywhere. An instance running Rocket League has no Servers page in its menu, no map pools and no server card on its dashboard — those belong to CS2, and CS2 is not the game running.

## What the CS2 module needs

The CS2 module is the only one with anything outside Auto Tournament, because it is the only one that talks to game servers:

- [Auto Tournament CS2](/cs2/plugin) (formerly MatchZy Enhanced), a plugin on each CS2 server. Required.
- [CS2 Server Manager](/cs2/server-manager), a tool that installs and runs CS2 servers on one Linux machine. Optional, and the easiest way to get servers.

Manual reporting needs nothing at all. See [Manual reporting](/guides/manual-reporting).

## What 3.0 changed

<Callout type="warn" title="In beta">
  3.0 is in beta. The current stable release is 2.4.x.
</Callout>

- **The core no longer contains CS2 code.** Everything that knows about Counter-Strike 2 — servers, maps, the veto, round events, demos — moved behind a boundary the rest of the app cannot reach across. The core runs a whole tournament without it.
- **Manual reporting is a second module**, so games Auto Tournament cannot watch are first-class: the bracket moves on, ratings change and Swiss pairs the next round exactly as they do for CS2.
- **The app follows the game.** Pages, menus and dashboard cards that belong to one game only appear when that game is the one running.
- **Games are packs.** The platform no longer carries a list of games in its code. Every game except Counter-Strike 2 is a pack you can add or remove from the **Modules** page.
- **New name everywhere.** The Docker image, repository and log lines move from "MatchZy Auto Tournament" to "Auto Tournament".

## Later

A game the platform *watches* — reading rounds off a server the way it does for CS2 — needs real code, not a pack. Installing that kind of module yourself is planned. Today the CS2 module is built in.

No date yet. When there is one it will be in the [changelog](/reference/changelog).

## Tournament formats

Single elimination, double elimination, round robin, Swiss and shuffle are **not** modules. They are part of the core and work with every game. See [Tournament formats](/guides/tournament-formats).
