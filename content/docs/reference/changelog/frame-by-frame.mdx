## v0.2.0

<p className="text-sm text-fd-muted-foreground">2026-10-23 · [Release on GitHub](https://github.com/Auto-Tournament/frame-by-frame/releases/tag/v0.2.0)</p>

Frame by Frame now runs the recorder's commands on exact frames, so a clip only renders slowly where it's slowed.

### What's new

- **Commands on exact frames.** The plugin swaps one function pointer, the client's `FrameStageNotify`, which the engine calls at the start of every frame. There it runs the lines the recorder writes to `csgo/frame-by-frame/actions.txt` (`<frame> <command>`). The recorder uses it to start each part of a clip on its exact frame at its own rate: 480 frames a game second where the clip is slowed, 240 everywhere else, with no seeking in between.
- **Faster recordings.** Capturing a 1080p 240 fps clip took about 40% less time on our test recorder (100 s instead of 167 s).
- **Fails safe.** If a CS2 update moves `FrameStageNotify`, the plugin sees a call it doesn't recognise, puts the pointer back and logs `frame actions off`. The recorder then records the whole clip at the slowed rate, as in 0.1.0: slower, never broken.
- **Hidden commands listed.** [docs/hidden-commands.md](https://github.com/Auto-Tournament/frame-by-frame/blob/master/docs/hidden-commands.md) lists every developer-only command the plugin unhides on a dedicated server.

The recorder (from Auto Tournament 3.0.0-beta.216) installs this version by itself.

## v0.1.0

<p className="text-sm text-fd-muted-foreground">2026-10-23 · [Release on GitHub](https://github.com/Auto-Tournament/frame-by-frame/releases/tag/v0.1.0)</p>

The first release of Frame by Frame, the CS2 plugin the Auto Tournament highlight recorder loads to record clips one frame at a time.

### What it does

- Makes CS2 unhide `startmovie`, so the game writes every frame of a demo and its own sound, at whatever pace the GPU manages. A clip comes out the same on any GPU.
- Makes one call, CS2's own `ICvar::StripDevelopmentFlags()`, after checking that the function really is that one. If a CS2 update moves it, the plugin logs it and does nothing.
- No hooks, no Metamod, no CounterStrikeSharp.

The recorder installs it and adds it to `gameinfo.gi` only while its own CS2 runs.
