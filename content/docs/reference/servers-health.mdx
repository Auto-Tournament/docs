The **Servers** page shows a status chip, and sometimes extra warning chips, for
each connected game server. This page explains what each one means.

## Offline

The server's fleet link is down: Auto Tournament has had no heartbeat from it.

- Check that the server is running: its machine's tile on the **Servers** page, or `csm status` on the machine. Start it from the tile.
- Check that the server can reach the site at the address in **Settings → Counter-Strike 2 → Webhook URL**, over HTTPS. A firewall or DNS change on either side is the usual cause.
- If Auto Tournament runs in Docker on the same machine as the server, use the LAN IP, not `localhost`.

A match that was on the server waits for it, and the **Needs you** list on the manage page says so. Failover can move it to another server.

## Waiting to enroll

The server was added but has never connected. With [CS2 Server Manager](/cs2/server-manager) this happens on its own when the server starts the first time; check the machine's tile for an error. A server set up by hand needs its enrollment token, see [Fleet mode](/cs2/ready-up/fleet#enroll-a-server).

## Revoked

An admin removed the server's credentials, so the site refuses it. Enroll it again to use it.

## CS2 update required

Valve released a CS2 update and the server is behind. Auto Tournament blocks
outdated servers from new allocations and tournament start.

```bash
csm update-game
csm restart
```

Without CS2 Server Manager, update the server with SteamCMD and restart it.
The update monitor of
CS2 Server Manager can do this for you, see
[Plugins and updates](/cs2/server-manager/updates#the-update-monitor).
