🧪 **New betas: Auto Tournament 3.0.0-beta.14, Ready Up 0.1.0-beta.1, CS2 Server Manager 1.12.0**

**Ready Up** is our own CS2 match plugin. No Metamod, no CounterStrikeSharp. It replaces the old Auto Tournament plugin with everything it did, and works with or without the platform.

What's new:
🖥️ One CS2 install, many servers (csm instance mode)
🔗 Add a machine with one command: `csm link`
🔁 Server crashed? The match resumes from the last round
📈 Servers start and stop to fit the bracket
🎯 Practice: replay a pro round with bots, lineups, rethrow
🪝 Webhooks and a teams API for event websites

These are betas. Try them on test servers, not your main event.
